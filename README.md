# DXC

https://xiseshtormx.github.io/dxc/

Статическая сборка DXC: email-регистрация, роли, аватары, кабинеты клиентов и цветовые классы. Для писем владелец подключает подтверждённого отправителя и API-ключ в Настройках. API, база и файлы работают отдельно; исходный реестр и ключи сюда не публикуются.
